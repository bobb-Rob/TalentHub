## 🎯 Core Project Scope

### What You're Building

A **sleek, responsive personal portfolio website** featuring:

- **Hero Section** – Compelling introduction with CTA buttons
- **Project Gallery** – 4-6 featured projects with live demos & GitHub links
- **About & Skills** – Professional narrative + 12-15 technical skills
- **Contact Form** – Validated form with EmailJS email delivery
- **Responsive Design** – Mobile-first, works perfectly on all devices
- **Performance** – Lighthouse score ≥ 90

### Tech Stack

| Component | Purpose | Why Chosen |
|-----------|---------|-----------|
| **React** | UI Framework | 12+ years stable, huge ecosystem |

| **TailwindCSS** | Styling | Responsive framework, fast development |
| **EmailJS** | Email Service | No backend required, free tier (200 emails/mo) |
| **Zustand** | State Management | Lightweight, simple API |

## 📋 Software Engineering Principles Applied

### ✓ Four Core Process Activities

1. **SPECIFICATION** (Week 1)
   - Detailed requirements (DFR-1 through DFR-7)
   - Feasibility study & stakeholder analysis
   - Complete with acceptance criteria

2. **DESIGN & IMPLEMENTATION** (Week 2)
   - Architecture diagram
   - Database schema (JSON structure)
   - UI/UX wireframes
   - Component specifications
   - Technology selection justified

3. **VALIDATION** (Weeks 7-8)
   - Testing strategy (unit, integration, E2E, acceptance)
   - Lighthouse performance audit
   - WCAG 2.1 AA accessibility compliance
   - Mobile responsiveness testing

4. **EVOLUTION** (Post-Launch)
   - Maintenance plan
   - Future enhancement backlog
   - Monitoring setup
   - Analytics integration

### ✓ Process Model: Hybrid Incremental + Prototyping

**Why This Model?**
- **Waterfall Phase:** Upfront specification prevents mid-project surprises
- **Agile Implementation:** 2-week sprints enable early feedback
- **Prototyping:** MVP in Week 4, demo for feedback before continuing
- **Risk Management:** Risks identified and mitigated each sprint

**Sprint Schedule:**
- Weeks 1-2: Specification & Design
- Weeks 3-4: Sprint 1 (MVP: Hero + Projects)
- Weeks 5-6: Sprint 2 (Features: About + Contact Form)
- Weeks 7-8: Sprint 3-4 (Polish & Deploy)

### ✓ Component Analysis & Reuse

**Strategy:** Reuse proven components instead of building custom

| Component | Source | Analysis Result |
|-----------|--------|-----------------|
| React | npm | ✅ Use (battle-tested, 12+ years) |
| TailwindCSS | npm | ✅ Use (responsive + accessibility) |
| EmailJS | npm | ✅ Use (no backend needed) |
| React Router | npm | ✅ Use (standard for SPAs) |
| Custom CSS | (build from scratch) | ❌ Don't build – use Tailwind |
| Custom Email Backend | (build from scratch) | ❌ Don't build – use EmailJS |
